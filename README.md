# CodeAlpha_EDA

# 🎮 Video Game Sales - Exploratory Data Analysis

## 📌 Project Overview

This project focuses on **Exploratory Data Analysis (EDA)** of a video game sales dataset.

The goal is to clean and prepare the dataset, explore patterns and trends, and answer meaningful questions using statistical analysis and data visualization.

This project was completed as part of **Task 2: Exploratory Data Analysis (EDA)** during my internship.

---

## 🎯 Objectives

- Understand the structure and characteristics of the dataset
- Identify and handle missing values
- Clean and transform data for analysis
- Explore patterns and trends in video game data
- Analyze genres, platforms, publishers, sales, and user scores
- Create meaningful visualizations to communicate findings
- Identify potential data issues and anomalies

---

## 🛠️ Tools & Technologies

- **Python**
- **Pandas** – Data cleaning and analysis
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical data visualization
- **Jupyter Notebook** – Development environment
